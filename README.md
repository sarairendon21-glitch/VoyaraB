# VoyaraB

VoyaraB es una aplicación web estática desarrollada con HTML, CSS y JavaScript puro. Está pensada como una experiencia de viaje para usuarios que desean buscar y reservar vuelos, hoteles, transporte y servicios para mascotas.

## Estructura del repositorio

- `index.html` - Interfaz principal de la aplicación.
- `estyles.css` - Estilos y diseño visual de la página.
- `script.js` - Lógica de interacción, navegación y formularios.
- `logo.jpg` - Logo utilizado en la cabecera.
- `images/` - Carpeta con recursos gráficos utilizados en la aplicación.

## Características clave

- Cabecera interactiva con colores dinámicos por sección.
- Login/registro/recuperación de contraseña con formularios reales.
- Búsqueda de vuelos, hoteles, transporte y servicios especiales para mascotas.
- Hero de hoteles con rotación de imágenes de fondo.
- Animaciones sutiles para mejorar la experiencia de usuario.

## Mejoras aplicadas

- Se agregó `logo.jpg` como logo principal en la cabecera.
- Se hizo clicable el logo y el nombre de la marca para regresar al inicio.
- Se añadió una microanimación de entrada del logo.
- Se implementó un topbar profesional con gradientes y efecto de scroll.

## Uso

1. Coloca el proyecto en un servidor local (por ejemplo XAMPP).
2. Abre `index.html` en el navegador.
3. Usa el menú superior para navegar entre secciones.
4. Inicia sesión o crea una cuenta en la modal de autenticación.

## Notas

- El envío de recuperación de contraseña se simula con una petición POST a `jsonplaceholder.typicode.com/posts`.
- Los usuarios registrados se almacenan localmente en el navegador usando `localStorage`.
